## 📌 Project Overview
This project provides an in-depth analysis of global video game sales performance[cite: 2]. Using historical market data, the interactive dashboard breaks down sales metrics across geographic regions (NA, EU, JP, and Others), identifies top-performing game genres and publishers, and highlights the highest-selling titles globally[cite: 2].

## 📊 Key Features & Insights
* **Global Sales Summary:** High-level KPIs showing regional and total sales distribution[cite: 2].
* **Regional Breakdown:** Market share analysis comparing North America, Europe, Japan, and Other regions[cite: 2].
* **Publisher Analysis:** Evaluation of total games published by industry leaders (e.g., EA, Activision, Ubisoft, Nintendo)[cite: 2].
* **Genre Trends:** Performance ranking of top genres such as Sports, Platform, Shooter, and Action[cite: 2].
* **Top Titles & Platforms:** Deep dive into top-selling games (e.g., GTA V, Wii Sports) and platform-specific performance (PC, PS3, PS4, X360, etc.)[cite: 2].

## 🛠️ Tools & Technologies Used
* **Power BI / Excel:** Data modeling, DAX measures, dynamic filters (Slicers), and visual design[cite: 2].
